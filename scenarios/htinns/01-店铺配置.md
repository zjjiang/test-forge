# 店铺配置 业务描述

> 主流程 + 旁路（权限边界 / 校验报错 / 非 admin 视角 / 提醒关闭），对应用例 M01-M11、S01-S10

## 环节

1. **管理员登录平台**：登录成功进入平台
2. **新增E2E店铺（含列表走查）**：打开配置页可见入口与全量列表；新增店铺后 flash 提示已创建、行状态在营
3. **信科凭证填写与回显**：保存2个字段后 ID 明文回显、Cookie 掩码；再开编辑弹窗输入框为空
4. **停用与再启用**：停用后 flash 与行状态翻转；再启用恢复在营
5. **凭证失效提醒浮层**：顶栏徽标亮起，浮层列出失效店铺与去配置入口，可重新检测
6. **搜索店铺**：全名精确命中恰1行，搜索框保留完整关键词
7. **新增校验与权限兜底**：留空提交被HTML5拦截；重名创建失败且danger；管理员行无停用按钮、直接POST停管理员403
8. **凭证提醒本次不再显示**：点不再显示写入sessionStorage，刷新后徽标保持隐藏
9. **管理员退出登录**：悬停菜单退出后回到/login
10. **店侧只读视角与403边界**：非admin恰1行本店、凭证全掩码、留空保存warning、创建/停用接口403、无搜索框与分页
11. **收尾登录并停用E2E店留档**：若E2E店仍在营则停用留档
